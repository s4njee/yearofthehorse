# Support matrix delta

Story 1.6. What Year of the Horse leans on beyond Fire Temple's [support matrix](../../firetemple/docs/support-matrix.md) and Wind Temple's [delta](../../windtemple/docs/support-matrix.md). Probed by `node experiments/support-probe.mjs` in headless Chrome 156 on this Mac (Apple M1 Max), with the dev server running; raw results in [studies/support-probe.json](studies/support-probe.json).

| What                                                                          | Why this family needs it                                                                                                  | Result here                                                                                                                                                                                                                                                        |
| ----------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| A `display-p3` canvas                                                         | Barium green, strontium red and copper blue are outside sRGB (story 2.2)                                                  | Configured and read back as `display-p3`. Headless Chrome reports no P3 display (`(color-gamut: p3)` is false), so the effect page falls back to sRGB there. A Mac's built-in screen covers P3 and should report it in a normal window, which was not checked here |
| An `rgba16float` canvas with `toneMapping: 'extended'`, and with `display-p3` | Bursts and neon brighter than paper white, on HDR screens                                                                 | Both configure. Headless Chrome reports no HDR display (`(dynamic-range: high)` false)                                                                                                                                                                             |
| Storage buffers read in the vertex stage                                      | Instanced stars reading shells and flight tables                                                                          | Offered (10 in the vertex stage). WebGPU's compatibility mode allows none by default, so `peony-display` reads its shells (640 bytes) and tables (10 kB) from uniform buffers instead, which every device has                                                      |
| `drawIndirect` with counts a compute pass wrote                               | Emitters drawing their live stars (story 2.4's stateful shells)                                                           | Works: a count of 300 written in a compute pass drew 300 instances                                                                                                                                                                                                 |

| `rg11b10ufloat-renderable`                                                    | A cheaper HDR scene target                                                                                                | Offered                                                                                                                                                                                                                                                            |

## What this changes

- **Use uniforms, not storage, where a vertex shader reads small tables.** It costs nothing here and keeps effects running in compatibility mode.
- **Ask for P3 and check what you got.** `configureCanvasWide` reads the configuration back; the effect maps its colours into whichever gamut it got (`starColours(gamut)`). Headless runs, the tests and posters are all sRGB.
- **Not measured:** an integrated GPU, a phone, Safari and Firefox (story 13.2).
